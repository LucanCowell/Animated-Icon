# Animated-Icon
This is a testing repository to create an animated logo

This animated logo shifts to different expressions at a set time, typically for 10 seconds. It currently has 8 expressions in the rotation but 11 total expressions that can be added to the rotation.

This repository was created so that I could test an idea that I had in order for LucanWebDesigns websites to stand out. By creating this animated logo, I have proved that it can work quite simply, randomised, and relatively smooth transition between expressions or images depending on the websites needs.

This same idea will later be added to future clients websites (if asked for) and will build up the skills for stronger versions, ones that transition smoother and create an engaging animation depending on the logo of the client.
